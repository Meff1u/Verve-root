feat: search and import from YouTube, SoundCloud and Spotify with smooth animations

Server
- Sources: YouTube Music search/import/download (youtubei.js, player script run
  in an isolated vm), SoundCloud search/import with HLS joined without ffmpeg and
  DRM tracks filtered out, Spotify import matched to YouTube Music for playback.
- Audio is downloaded once on the server, cached for the current and next track
  and streamed to clients through GetAudio in 200 KB chunks.
- Search, ImportLink and AddTracks replace adding direct file links; tracks that
  can't be downloaded are skipped.

Client
- Live search with a YouTube Music / SoundCloud switch, import dialog for links,
  chunked audio loading with progress and next-track prefetch.
- Motion-based animations: view transitions, sliding tab highlight, cover and
  title transitions, animated controls, staggered lists, drag-to-reorder queue
  and a frame-smooth seek bar; all respect reduced motion.
